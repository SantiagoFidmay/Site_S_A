Fundamentos de Banco de Dados

Estudamos o papel dos SGBDs (Sistemas Gerenciadores de Banco de Dados), responsáveis por armazenar, manipular e garantir a segurança das informações, além de conhecermos os diferentes tipos de bancos de dados, cada um adequado a necessidades específicas, desde empresas até aplicações do cotidiano. Outro ponto importante foi a modelagem de banco de dados, que nos mostrou a importância de planejar antes de implementar, utilizando ferramentas como o MER (Modelo Entidade-Relacionamento) e o DER (Diagrama Entidade-Relacionamento). Esses recursos nos ajudaram a visualizar de forma clara como as entidades se conectam, tornando o entendimento mais acessível.

Com isso, este site reúne parte desse aprendizado, servindo como registro do nosso desenvolvimento ao longo das aulas e como apoio para futuros estudos. Mais do que conteúdo técnico, ele reflete nossa evolução e a compreensão de que os bancos de dados são a base da informação organizada no mundo atual.




O que é um SGBD? Tipos e Aplicações

Um Sistema Gerenciador de Banco de Dados (SGBD) é um software que possibilita a criação, a manipulação e a administração de bancos de dados, permitindo que as informações sejam armazenadas, consultadas, alteradas e excluídas de forma organizada e segura. Existem diferentes tipos de SGBD, como os hierárquicos, que organizam os dados em estruturas de árvore; os de rede, que trabalham com relacionamentos mais complexos; os relacionais, que são os mais comuns e utilizam tabelas para organizar os dados, como o MySQL e o PostgreSQL; os orientados a objetos, que unem a programação a bancos de dados; e os NoSQL, voltados para dados não estruturados e escalabilidade, como o MongoDB. As aplicações dos SGBDs estão presentes em praticamente todas as áreas, desde sistemas bancários e plataformas de comércio eletrônico até redes sociais, saúde e educação.


Quais os principais bancos de dados?

Relacionais: MySQL, PostgreSQL, Oracle, SQL Server, MariaDB. NoSQL: MongoDB, Cassandra, Redis, CouchDB. Na nuvem: Firebase, Amazon Aurora, Google BigQuery, Azure Cosmos DB.

Quais os principais bancos de dados?

Os bancos de dados mais conhecidos variam entre relacionais e não relacionais. Entre os relacionais, destacam-se MySQL, PostgreSQL, Oracle, SQL Server e MariaDB, que trabalham de forma estruturada com tabelas. Já entre os bancos não relacionais, conhecidos como NoSQL, estão o MongoDB, Cassandra, Redis e CouchDB, que são utilizados em situações que exigem grande volume de dados e alta velocidade de acesso. Além disso, existem soluções em nuvem, como o Firebase, o Amazon Aurora, o Google BigQuery e o Azure Cosmos DB, que oferecem praticidade e escalabilidade para sistemas modernos.


O que é um dicionário de dados? Quais os tipos de dados de um banco de dados?

O dicionário de dados é um catálogo que descreve a estrutura de um banco de dados, registrando informações como nomes de tabelas, colunas, tipos de dados, relacionamentos e restrições. Ele funciona como uma espécie de manual que orienta a forma como o banco está organizado. Os tipos de dados mais comuns são os numéricos, como inteiros e decimais, os de texto, como campos de caracteres e textos longos, os de data e hora, que registram informações temporais, os booleanos, que armazenam valores verdadeiro ou falso, e os binários, que permitem guardar arquivos como imagens e documentos.


O que é uma modelagem de banco de dados? E o modelo DER? MER?

A modelagem de banco de dados é o processo de planejar e organizar como os dados serão estruturados e relacionados dentro de um sistema. Esse planejamento garante maior eficiência no armazenamento e recuperação das informações. O modelo DER, ou Diagrama Entidade-Relacionamento, é uma representação gráfica que mostra as entidades de um banco de dados, seus atributos e os relacionamentos entre elas. Já o MER, ou Modelo Entidade-Relacionamento, é a descrição teórica dessas entidades, atributos e relacionamentos, que pode depois ser representada graficamente por meio do DER.


Diagrama DER

Um exemplo simples de um diagrama DER pode ser observado em um sistema de biblioteca. Nesse caso, as entidades seriam Livro, Autor, Usuário e Empréstimo. O relacionamento entre elas poderia ser descrito da seguinte forma: um autor escreve vários livros, um usuário pode realizar diversos empréstimos e um empréstimo pode conter vários livros. No DER, essas entidades aparecem representadas por retângulos, os atributos surgem em elipses e os relacionamentos são indicados por losangos.


Diagrama MER

Tomando o mesmo exemplo do sistema de biblioteca, o modelo MER descreve de maneira teórica as entidades e seus atributos. O Livro possui atributos como código, título e ano; o Usuário possui matrícula, nome e telefone; o Autor tem código e nome. Os relacionamentos podem ser descritos como "escreve", que liga Autor e Livro, e "realiza", que conecta Usuário e Empréstimo. Esse modelo é uma forma conceitual de entender a estrutura dos dados antes de transformá-la em um diagrama gráfico, como o DER.


BR Modelo

O BR Modelo é uma ferramenta gratuita voltada para a criação de modelos de banco de dados. Ele permite construir diagramas conceituais, lógicos e físicos de forma visual, organizando entidades, atributos e relacionamentos com precisão. A ferramenta ajuda estudantes e profissionais a planejarem bancos de dados de maneira estruturada, evitando erros na fase de implementação. Além disso, o BR Modelo possibilita validar modelos, exportar diagramas e gerar scripts SQL automaticamente, tornando o processo de modelagem mais rápido e padronizado. Simples, leve e intuitivo, é amplamente utilizado em cursos de tecnologia e em projetos de desenvolvimento de sistemas.
