Fundamentos de Tecnologia da Informação e Redes



O que é o Hardware de computadores?

Hardware é a parte física do computador, formada por peças eletrônicas e mecânicas, como monitor, teclado, HD, memória e placas. Sem ele, o software não teria onde rodar. A placa-mãe é o principal circuito do computador, responsável por conectar todos os componentes (processador, memórias, placas de vídeo, HD/SSD, portas USB, etc.), permitindo que se comuniquem. O processador (CPU) é chamado de cérebro da máquina. Ele interpreta e executa instruções, realiza cálculos e toma decisões lógicas, controlando praticamente tudo o que acontece no sistema. A memória principal (RAM) é uma memória temporária e volátil: armazena apenas os dados que estão em uso no momento. Ao desligar o computador, os dados nela são apagados. Quanto mais RAM, maior a capacidade do PC em executar várias tarefas ao mesmo tempo.


O que é um sistema operacional?

O sistema operacional é um conjunto de programas que gerencia todos os recursos do computador, tanto de hardware quanto de software. Ele controla o uso da memória, organiza os processos no processador, gerencia os arquivos nos dispositivos de armazenamento e cuida da comunicação com periféricos como impressoras, teclados e mouses. Além disso, fornece a interface que o usuário utiliza, podendo ser em modo gráfico, com janelas e ícones, ou em modo texto, por comandos. Sem um sistema operacional, o computador não funcionaria de forma prática, pois seria muito difícil controlar manualmente cada recurso. Entre os mais conhecidos estão o Windows, que é muito usado em computadores pessoais e empresas; o Linux, bastante usado em servidores e também em desktops; o macOS, exclusivo dos computadores Apple; e o Android, que é o sistema mais utilizado em dispositivos móveis.


O que é o sistema de arquivos?

O sistema de arquivos é a estrutura que organiza como as informações ficam gravadas em dispositivos de armazenamento, como HDs e SSDs. Ele define como os dados são criados, acessados e recuperados. Em modo texto, no CMD, o sistema é controlado por comandos digitados, como criar pastas, listar e mover arquivos. Já no modo gráfico, como no Explorer do Windows, a navegação é feita por janelas, ícones e menus, tornando o uso mais intuitivo.


O que é software de escritório?

Softwares de escritório são programas criados para facilitar tarefas de produtividade, como a elaboração de documentos, planilhas e apresentações. O Microsoft Word, por exemplo, é usado para escrever textos e relatórios; o Microsoft Excel serve para cálculos, tabelas e gráficos; e o Microsoft PowerPoint é usado para apresentações em aulas, reuniões e palestras. Também existem alternativas como LibreOffice e Google Docs, que cumprem funções semelhantes.





Fundamentos de Redes


O que são Redes de Computadores?


Redes de computadores são conjuntos de dispositivos interligados que podem trocar informações entre si. Esses dispositivos utilizam meios de comunicação como cabos, ondas de rádio ou fibra óptica e seguem regras chamadas protocolos para que a comunicação funcione corretamente. O objetivo é permitir compartilhamento de dados, recursos e acesso à internet entre computadores, celulares, servidores e outros equipamentos.


O que é uma Rede mínima?


Uma rede mínima é a forma mais simples possível de uma rede, formada por apenas dois dispositivos capazes de se comunicar entre si. Isso pode acontecer por um cabo conectando um computador ao outro ou por uma conexão sem fio usando um roteador. Mesmo sendo pequena, essa estrutura já permite troca de arquivos, envio de mensagens ou testes de conectividade.


O que é a internet?


A internet é uma gigantesca rede mundial formada pela interconexão de milhões de redes menores. Ela funciona como a base de comunicação global que permite o uso de serviços como sites, e-mails, redes sociais, streaming, jogos online e muito mais. A internet é composta por cabos submarinos de fibra óptica, cabos terrestres, data centers, servidores, roteadores, satélites e provedores que transportam dados no mundo inteiro. A internet é composta por estruturas físicas e lógicas. Entre elas estão os cabos submarinos de fibra óptica, que conectam continentes; roteadores de grande porte que encaminham pacotes de dados; data centers que armazenam e processam informações; pontos de troca de tráfego onde provedores interligam suas redes; satélites e torres de telecomunicação; provedores de internet que conectam usuários; além de protocolos como IP, TCP e DNS, que organizam toda a comunicação.


O que é a web?


A web é um serviço que funciona dentro da internet e é responsável pelos sites que acessamos no navegador. Ela é formada por páginas, links e servidores que enviam documentos ao navegador por meio do protocolo HTTP ou HTTPS. Embora seja a parte mais visível para os usuários, a web é apenas um dos muitos serviços que utilizam a internet como base, junto com e-mail, FTP, streaming e outros.


O que é o mapa de fibra óptica?


O mapa de fibra óptica é uma representação visual dos cabos de fibra que ligam países e continentes. Ele mostra por onde passam os cabos terrestres e submarinos que carregam grande parte dos dados da internet mundial. Esses mapas revelam as rotas principais pelas quais o tráfego global de informações circula. O mapa global consiste em linhas que atravessam os oceanos conectando pontos na América, Europa, África, Ásia e Oceania. Os principais cabos submarinos são representados em cores distintas e indicam os pontos onde chegam nos continentes. Esse tipo de mapa está disponível em plataformas como Submarine Cable Map, mostrando toda a infraestrutura real que mantém a internet funcionando globalmente.




Quais os componentes de hardware de uma rede Wi-Fi?


Uma rede Wi-Fi é composta pelo modem que recebe o sinal da operadora, pelo roteador Wi-Fi que converte esse sinal e o transmite por ondas de rádio, por antenas internas ou externas que melhoram o alcance, por access points que ampliam a cobertura em locais grandes, além dos dispositivos que se conectam, como celulares, notebooks e televisores. Em redes corporativas, também existem switches ligados ao roteador e aos access points para organizar os cabos que alimentam os equipamentos de rede. Mesmo uma rede Wi-Fi depende de cabos internos para interligar roteador e modem.


Quais os componentes de hardware de uma rede local com cabo de rede?


Uma rede cabeada é formada por cabos Ethernet, plugues RJ-45, switches que distribuem o sinal entre vários dispositivos, roteadores que conectam a rede local à internet, placas de rede presentes em cada equipamento, patch panels para organização da fiação e o modem que recebe o sinal do provedor. Redes com cabo são mais estáveis e oferecem menor latência, sendo muito usadas em escritórios, laboratórios, escolas e servidores.


O que é um protocolo de comunicação?


Um protocolo de comunicação é o conjunto de regras e padrões que define como os dados devem ser enviados, transmitidos e interpretados entre dispositivos. Ele especifica desde o formato dos pacotes até como eles devem ser ordenados, confirmados e entregues. Protocolos garantem que dispositivos diferentes, de marcas e sistemas distintos, consigam se comunicar perfeitamente.


O que é o modelo OSI?


O modelo OSI é uma divisão teórica da comunicação em sete camadas: física, enlace, rede, transporte, sessão, apresentação e aplicação. Cada camada representa um conjunto de funções, desde enviar sinais elétricos pelo cabo até interpretar dados que chegam a um software. Embora não seja o modelo usado na prática da internet, ele é fundamental para estudos de redes e para entender como os dados trafegam.


E o modelo TCP/IP?


O modelo TCP/IP é o modelo real usado na comunicação da internet. Ele divide toda a comunicação em quatro camadas: acesso à rede, internet, transporte e aplicação. É ele que define como pacotes são criados, enviados, roteados por grandes distâncias e entregues ao destino. Todo tráfego da internet funciona baseado nesse modelo, incluindo sites, e-mails, jogos e APIs.


O que é o protocolo IPv4 e IPv6?


O IPv4 é o padrão tradicional de endereçamento da internet. Ele usa endereços numéricos de 32 bits separados por pontos, como 192.168.0.10. Foi criado nos anos 80 e permite cerca de 4,3 bilhões de endereços, número que hoje é insuficiente devido ao aumento de dispositivos conectados no mundo. Já o IPv6 é o novo padrão que substitui o IPv4 e usa endereços de 128 bits, permitindo uma quantidade enorme de endereços disponíveis. Ele também melhora a segurança, possui estrutura mais moderna e facilita a roteação. Seus endereços têm formato hexadecimal, como 2001:db8:85a3::8a2e:370:7334.


Como IP e TCP são configurados em Node.js?


Em Node.js, a configuração do IP e da porta é feita ao criar o servidor. O programador define a porta e, se necessário, o endereço onde o servidor vai escutar. O sistema operacional cuida do IP real da máquina, enquanto o Node usa módulos como http ou frameworks como Express para receber e enviar dados usando o protocolo TCP por baixo. Quando você usa server.listen(3000, '0.0.0.0'), está configurando porta e IP para receber conexões.


O que é o protocolo HTTP e HTTPS?


O HTTP é o protocolo que permite a comunicação entre o navegador e o servidor web. Ele organiza as requisições feitas pelo cliente e as respostas enviadas pelo servidor, como páginas HTML, imagens, arquivos ou dados no formato JSON. O HTTPS é a versão segura do HTTP. Ele utiliza criptografia SSL/TLS para garantir que os dados transmitidos não sejam interceptados ou modificados por terceiros. Ele protege logins, transações bancárias, dados privados e qualquer comunicação sensível entre cliente e servidor.


Exemplo de framework HTTP em Node.js:


Um framework HTTP em Node.js é uma ferramenta que facilita criar servidores e APIs. O mais usado é o Express, que torna simples tarefas como criar rotas, enviar respostas, receber dados do frontend e organizar o código. Ele funciona com “middlewares”, que são funções ordenadas pelas quais toda requisição passa até receber uma resposta. O Express deixa o backend mais rápido de desenvolver, mais organizado e muito mais fácil de conectar com bancos de dados, autenticação e qualquer sistema do frontend. É basicamente a forma prática e profissional de trabalhar com HTTP dentro do Node.js.
